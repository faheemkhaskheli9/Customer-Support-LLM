# Module 01: Foundations

## Goal
Understand what an LLM can and cannot guarantee in a support workflow.

## Topics
Tokens and context windows; next-token generation; temperature and sampling; model capabilities; latency and cost; deterministic code around probabilistic output.

## Lab
Send the same support question at multiple temperatures and record factuality, verbosity, latency, and token usage.

## Check
Explain why fluent output is not evidence of correctness, and name one control outside the prompt that reduces risk.

# Module 07: Healthcare Project

## Goal
Apply the system patterns to a healthcare support assistant with strict boundaries.

## Topics
Project scope; medication and symptom search; terminology; PHI minimization; medical disclaimers; escalation; source freshness; clinical limitations.

## Lab
Design a response flow that gives sourced educational information, avoids diagnosis or prescribing, and routes urgent symptoms to a human or emergency guidance.

## Check
The system must clearly separate administrative support, general education, and clinical decisions.

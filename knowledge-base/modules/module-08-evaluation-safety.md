# Module 08: Evaluation and Safety

## Goal
Measure whether the assistant is useful and safe for the workflows that matter.

## Topics
Golden datasets; retrieval recall; groundedness; rubric-based judging; red teaming; privacy tests; bias; regression thresholds; incident review.

## Lab
Evaluate the same cases before and after a prompt or retriever change. Report pass rate, citation coverage, unsafe advice, latency, and cost.

## Check
A score without a case-level rationale is not enough to debug a failed support interaction.

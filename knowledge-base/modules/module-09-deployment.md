# Module 09: Deployment

## Goal
Operate the assistant as a monitored production service.

## Topics
Service boundaries; secrets; queues; caching; scaling; observability; model routing; rollout and rollback; data retention; incident response.

## Lab
Write a deployment runbook with health checks, dashboards, alert thresholds, a kill switch, and a fallback to human support.

## Check
The service can degrade gracefully when the model, vector store, or tool dependency is unavailable.

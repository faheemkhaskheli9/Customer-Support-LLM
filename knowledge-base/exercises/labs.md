# Labs

1. Compare model settings on the same support cases.
2. Add typed validation and failure handling to an API wrapper.
3. Build and inspect an idempotent document ingestion pipeline.
4. Add retrieval filters, citations, and a no-evidence fallback.
5. Add a confirmation-gated account action tool.
6. Run a safety and quality evaluation report.
7. Write a deployment runbook and incident drill.

Each lab should include a hypothesis, fixture data, executable checks, and a short reflection on trade-offs.

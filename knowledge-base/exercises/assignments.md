# Assignments

## Assignment 1: Provider boundary
Design a typed provider interface with retries, timeout behavior, fake backend, and cost accounting.

## Assignment 2: Grounded support answer
Implement ingestion, retrieval, citations, and deterministic fallback. Include a retrieval test set.

## Assignment 3: Risk review
Threat-model prompt injection, data leakage, unsafe advice, tool misuse, and stale sources. Propose controls and tests.

## Assignment 4: Operations review
Produce dashboards, alerts, rollout gates, retention policy, and an incident runbook.

# Learning Outcomes

By the end, learners can:

1. Explain tokens, context windows, sampling, embeddings, and model limits.
2. Call an LLM API with retries, timeouts, structured output, and cost controls.
3. Design prompts that separate instructions, customer data, and retrieved evidence.
4. Build idempotent ingestion and grounded retrieval with source citations.
5. Add tools and bounded agent loops without giving the model unchecked authority.
6. Protect PII and support human escalation for uncertainty or high-risk requests.
7. Evaluate answer quality, retrieval quality, safety, latency, and cost with repeatable cases.
8. Deploy a support assistant with monitoring, rollback, and incident procedures.
